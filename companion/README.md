# Glove Clipboard (companion app)

โปรแกรมถาดระบบบน Windows ที่ sync ข้อความ clipboard ระหว่าง 2 เครื่องผ่านถุงมือ (ESP32)
Ctrl+C เครื่องหนึ่ง แล้ว Ctrl+V อีกเครื่องได้เลย ใช้ได้เฉพาะข้อความล้วน (รวมภาษาไทย/URL/โค้ดสั้นๆ ไม่เกิน 16384 ไบต์ ≈ ภาษาไทย 5,400 ตัวอักษร)

## ติดตั้ง (ทำทั้ง 2 เครื่อง)
```bash
pip install -r requirements.txt
```

## ใช้งาน
1. flash เฟิร์มแวร์ล่าสุดและ pair ถุงมือกับทั้งสองเครื่อง (ลบ "Glove Air Mouse" เก่าใน Windows ก่อน ถ้าเห็น service ไม่ครบ เพราะ Windows แคช GATT)
2. รันบนทั้งสองเครื่อง:
```bash
python app.py
```
   ไอคอนที่ถาดระบบ: เขียว = ต่อถุงมือแล้ว, เหลือง = กำลังต่อ, เทา = ยังไม่ต่อ, แดง = หยุดชั่วคราว
3. Ctrl+C บนเครื่อง A → เครื่อง B ได้รับและใส่ clipboard ให้เอง (มีแจ้งเตือน) แล้ว Ctrl+V

app หา address ของถุงมือเอง เพราะถุงมือที่ต่อ Windows อยู่จะไม่ advertise ทำให้สแกนหาชื่อไม่เจอ ลำดับการหา: `--address` → รายการอุปกรณ์ที่ pair ไว้ใน Windows → สแกนหาชื่อ ถ้าไม่เจอจะรอแล้วลองใหม่ (ถอยห่างสูงสุด 30 วินาที) ไม่เดา address เอง ดังนั้น **ต้อง pair ถุงมือกับ Windows ก่อน** (ดู address ได้จาก Serial ตอนบูต `Address: ...`) ระบุเองได้:
```bash
python app.py --address AA:BB:CC:DD:EE:FF
```

## ส่ง event ขึ้น ThingSpeak (ฟีเจอร์เสริม ไม่บังคับ)
ทุกครั้งที่ sync สำเร็จ (ทั้งฝั่งส่งและฝั่งรับ) กับทุกครั้งที่ลิงก์ BLE ต่อใหม่ ส่งขึ้น [ThingSpeak](https://thingspeak.com) ได้ ถ้าใส่ Write API Key:
```bash
python app.py --thingspeak-key YOUR_WRITE_API_KEY
```
ไม่ใส่ก็ทำงานปกติ ไม่ส่งอะไรขึ้น cloud เลย (เธรดที่ดูแลเรื่องนี้จะแค่ว่างเปล่า ไม่กินทรัพยากร)

**Field ที่ใช้ (channel เดียว):**
| field | ความหมาย |
|---|---|
| field1 | ความยาวข้อความที่ sync (ตัวอักษร) |
| field2 | ทิศทาง: `1` = ส่งออกจากเครื่องนี้, `2` = ได้รับเข้าเครื่องนี้ |
| field3 | ลิงก์ BLE ครั้งก่อนอยู่ได้กี่วินาทีก่อนหลุด (ส่งทุกครั้งที่ต่อ/ลองต่อใหม่ — เอาไว้ดูความเสถียรของ BLE เป็นกราฟย้อนหลัง) |

จำกัดอัตราไม่เกิน 1 ครั้งทุก 15 วินาที (ตามข้อจำกัดของ ThingSpeak free tier) — ถ้า event เข้ามาถี่กว่านั้นจะถูกข้าม ไม่ค้างสะสม

## กลไกที่ควรรู้
- **Multithreading:** มี 3 เธรดทำงานพร้อมกัน — (1) เธรดหลักรัน `pystray` icon loop, (2) เธรดรัน asyncio loop ของ BLE + เฝ้า clipboard, (3) `ThingSpeakWorker` เธรดแยกสำหรับยิง HTTP ขึ้น cloud โดยเฉพาะ รับงานจากอีกสองเธรดผ่าน `queue.Queue` (producer/consumer แบบ thread-safe ในตัว) กันไม่ให้เน็ตช้า/ThingSpeak ตอบช้าไปหน่วงงานหลัก (ดู `thingspeak_worker.py`)
- **กันลูป:** ตอนแอปเขียน clipboard เอง จะจำหมายเลข sequence ไว้ ไม่นับเป็นการ copy ใหม่ และข้ามข้อความที่ CRC เท่ากับที่เพิ่งส่ง/รับ
- **ข้าม:** ไฟล์, รูป, ข้อความว่าง, และข้อมูลที่ password manager ตั้งธง `ExcludeClipboardContentFromMonitorProcessing` หรือ `CanIncludeInClipboardHistory = 0`
- ข้อความบนถุงมือถูกล้างเองหลัง 60 วินาที
- เก็บได้ 1 ข้อความ ข้อความใหม่ทับของเก่า
